# Logs de Execução - Diagnóstico Comercial Voga.IA

Este diretório contém os logs de execução dos agentes e todas as saídas geradas durante o processo de diagnóstico.

## Estrutura de Outputs

- `01_data_validation_report.md` - Relatório de validação dos dados
- `02_data_governance_report.md` - Relatório de governança aplicada
- `03_metrics_calculation_report.md` - Métricas calculadas
- `04_business_insights_report.md` - Insights de negócio
- `05_monitoring_alerts_report.md` - Configuração de alertas
- `06_visualizations_report.md` - Visualizações criadas
- `07_dashboard_prototype_specs.md` - Especificações do dashboard
- `08_executive_report.md` - Relatório executivo final

## Logs dos Agentes

Todos os agentes geram logs detalhados de suas execuções, incluindo:
- Decisões tomadas
- Cálculos realizados
- Insights descobertos
- Recomendações geradas

## Gravação de Conversas

As conversas entre agentes são gravadas e podem ser acompanhadas em tempo real ou revisadas posteriormente para auditoria e aprendizado.
